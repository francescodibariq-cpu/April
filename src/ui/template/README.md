# Standalone UI template

Not part of the Fallen runtime. Used by:

- `npm run build:ui-template` → `"april UI.lua"` (demo catalog, no game features)
- `npm run build:ui` → `april_ui.lua` (real April catalog, still no game features)

Edit `catalog.lua` for demo tabs. The live game menu is `src/ui/catalog_*.lua`.
